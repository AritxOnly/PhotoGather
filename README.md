# 相集 · PhotoGather

在 Mac 上比对安卓导出目录和系统照片图库，预览后将选中的原文件导入「安卓迁移」相簿。iCloud 上传由系统「照片」完成。

## 在 Mac 上运行

需要 macOS 13 或更高版本和 Swift 编译器（Xcode Command Line Tools）。在仓库目录运行：

```sh
./build.sh
open build/PhotoGather.app
```

构建脚本为当前 Mac 的架构生成本地签名的 App。首次扫描时允许完整访问图库。在「照片」中确认系统照片图库已打开 iCloud 照片且同步完成。安卓导出目录可位于本机或外置磁盘。

## 一次迁移

1. 选择文件夹。扫描阶段只读，递归处理系统能按扩展名识别的图片和视频，跳过隐藏项和包目录。大视频采用分块哈希。图库原件仅在 iCloud 时，核验可能产生下载流量。
2. 默认快速扫描用原文件名或拍摄时间（前后 1 秒，同为照片或视频）寻找图库候选，再用原件 SHA-256 确认完全重复。改名且时间缺失的图库副本可能漏匹配。勾选「全库原件核验」可在扫描前读取可访问图库中的所有照片和视频主资源建立哈希索引，覆盖改名、缺时间的字节相同副本。此选项可能下载整个图库。文件夹内部按内容直接去重。
3. 使用筛选框查看疑似截图、完全重复和疑似匹配。点击行可预览。截图根据目录和文件名识别。只有未找到匹配的文件默认勾选。当前疑似匹配依赖元数据，无法全面识别压缩、转码、裁剪或去掉元数据的副本。
4. 点击导入并确认。逐项复制和核验临时文件，保留源文件。导入结果按项记录，失败项可查看原因后重扫。图库接收成功后，在「照片」中查看 iCloud 同步进度。导入期间请勿同时用其他工具导入同一批文件。

Google Takeout JSON、XMP 等旁车元数据以及安卓动态照片的动静配对尚未处理。动态照片可能只显示静态部分。首次迁移保留安卓原件。

## 回家回归

用一个小目录放入普通照片、相同文件的改名副本、已在图库的原件、截图、聊天软件压缩过的图片和长视频。

- 扫描后检查计数、分类、对应预览和默认勾选。取消导入，确认图库没有新增。
- 导入少量项目，在「安卓迁移」相簿核对数量、拍摄日期和视频播放。
- 再次扫描同一目录，已导入项目应显示完全重复并禁止勾选。
- 待「照片」同步完成，在同账号 iPhone 检查这些项目。

本地逻辑回归可执行 `./test.sh`。
